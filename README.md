# medicaledu (workspace)

This repository contains the Flutter application `medicaledu_app`.

## Getting started

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. Open the `medicaledu_app` folder in your editor or run from workspace root:

```bash
cd medicaledu_app
flutter pub get
flutter run
```

## Structure

- `medicaledu_app/` — the Flutter project scaffolded with `flutter create`.

## Notes

- Run `flutter analyze` for static analysis and `flutter test` to run tests.
- If you want a different package name or organization, recreate the project with `flutter create --org com.example medicaledu_app` or update `pubspec.yaml` and platform configs.
